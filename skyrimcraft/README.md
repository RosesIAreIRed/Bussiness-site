# SkyrimCraft 🐉🧱

Воксельна RPG у стилі **Skyrim × Minecraft** — повноцінний десктопний застосунок на **Electron + Three.js**.
Збирається в `.exe` для Windows однією командою.

![engine](https://img.shields.io/badge/engine-Three.js-blue) ![desktop](https://img.shields.io/badge/desktop-Electron-9cf)

## Можливості

**Зі світу Minecraft**
- Процедурно згенерований воксельний світ: трава, камінь, пісок, сніг, вода, дерева, руда, зруйнована вежа
- Ламання та будівництво блоків, 6 предметів у хотбарі
- Текстуровані блоки (процедурні текстури), instanced-рендеринг для швидкості

**Зі світу Skyrim**
- Шкали **Здоров'я / Магії / Витривалості** з регеном
- Прокачка рівнів, досвід, золото, **дерево навичок** (6 перків)
- Бій на мечі (з viewmodel у руках), магія **вогню** і **льоду**, Крик **«ФУС РО ДА»**
- 4 типи ворогів (бандит, дроуг, скелет-маг, крижана примара) + бос **Алдуїн Кубічний**
- Квести, золото, зілля, спливаючі числа урону

**Графіка / рушій**
- Динамічні **тіні** (PCF Soft), ACES tone mapping, sRGB
- **Шейдерне небо** з диском сонця та гало
- Повний **цикл день/ніч** (~2 хв): сонце, місяць, зорі, сутінкові кольори, туман
- Хмари, частинки, headbob, звукові ефекти (WebAudio, без файлів)

## Керування

| Клавіша | Дія | | Клавіша | Дія |
|---|---|---|---|---|
| `W A S D` | рух | | `Q` | Крик «ФУС РО ДА» |
| Миша | огляд | | `F` | магія вогню |
| `Пробіл` | стрибок | | `R` | магія льоду |
| `Shift` | біг | | `E` | взаємодія / підбір |
| `ЛКМ` | атака / ламати блок | | `P` | дерево навичок |
| `ПКМ` | ставити блок / пити зілля | | `Esc` | пауза |
| `1–6` | вибір предмета | | `F11` / `F12` | повний екран / DevTools |

**Мета:** дійди до 3 рівня, активуй вівтар у центральній вежі (`E`) і здолай дракона.

## Запуск (розробка)

```bash
cd skyrimcraft
npm install
npm start
```

## Збірка `.exe` для Windows

```bash
cd skyrimcraft
npm install
npm run dist
```

Готові файли з'являться в теці `dist/`:
- `SkyrimCraft-1.0.0-x64.exe` — інсталятор (NSIS, з ярликами)
- `SkyrimCraft-1.0.0-portable.exe` — портативна версія (без встановлення)

> **Примітка:** збирати Windows-`.exe` найнадійніше на Windows. На Linux/macOS
> electron-builder може зібрати через Wine, але офіційно рекомендується цільова ОС.
> Для Linux: `npm run dist:linux` (створить `.AppImage`).

### Іконка (необов'язково)
Поклади `build/icon.ico` (256×256) та `build/icon.png`, щоб задати власну іконку.
Без них використовується стандартна іконка Electron.

## Структура

```
skyrimcraft/
├── package.json      # залежності + конфіг electron-builder
├── main.js           # головний процес Electron (вікно)
├── preload.js        # безпечний міст (contextIsolation)
└── src/
    ├── index.html    # HUD та меню
    ├── style.css     # стилі інтерфейсу
    ├── game.js       # рушій гри (увесь геймплей)
    └── three.min.js  # Three.js (vendored, офлайн)
```
