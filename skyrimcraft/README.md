# SkyrimCraft 🐉🌲

3D action-RPG у стилі **Skyrim** — повноцінний десктопний застосунок на **Electron + Three.js**.
Збирається в `.exe` для Windows однією командою.

![engine](https://img.shields.io/badge/engine-Three.js-blue) ![desktop](https://img.shields.io/badge/desktop-Electron-9cf)

## Можливості

> **Новий 3D-рушій:** справжній гладкий ландшафт (heightmap), шейдерна вода з хвилями,
> low-poly 3D дерева/каміння/руда, інстансована трава з вітром, округлі 3D істоти — **жодних кубів**.

**Світ**
- Процедурний **острів** із гладким ландшафтом і природними берегами (heightmap + шум)
- **7 біомів**: ліс, рівнини, луг, пустеля, сніжні гори, **вулкан** (лавовий кратер), **болото**
- **Low-poly 3D об'єкти**: дуби/сосни/берези, валуни, світні рудні жили (вугілля/залізо/самоцвіт/золото/обсидіан)
- **Інстансована трава** з анімацією вітру, квіти й гриби для збору
- Плавне змішування біомів через вершинні кольори ландшафту

**Збір ресурсів і крафт**
- **Рубай** дерева (ЛКМ), **копай** каміння та рудні жили; ноди відновлюються з часом
- **Збирай** квіти/гриби (E), знаходь **скрині** зі скарбами
- **Майстерня (C)**: палиці, факели, стріли, печеня, зілля (здоров'я/мани),
  мечі (камінь → залізо → самоцвіт → обсидіан), бойова сокира, **лук** (G), броня 4 рівнів
- Споряджена зброя/броня показані в HUD; кращі знаряддя = більше урону/захисту

**Фауна**
- Мирні тварини: **олень, кролик, курка, кабан** — блукають, тікають, дають м'ясо/шкуру/перо/кістки
- Хижий **вовк** і людиноподібні вороги (бандит, дроуг, скелет-маг, крижана примара) + бос-дракон

**Зі світу Skyrim**
- Шкали **Здоров'я / Магії / Витривалості** з регеном
- Прокачка рівнів, досвід, золото, **дерево навичок** (6 перків)
- Бій на мечі (з viewmodel у руках), магія **вогню** і **льоду**, Крик **«ФУС РО ДА»**
- 4 типи ворогів (бандит, дроуг, скелет-маг, крижана примара) + бос **Алдуїн Кубічний**
- Квести, золото, зілля, спливаючі числа урону

**Механіки**
- **Голод** — їж м'ясо/печеню, інакше падає здоров'я
- **Магія**: вогонь (F), лід (R), **блискавка-ланцюг** (V), **лікування** (H)
- **Крики**: «ФУС РО ДА» (Q), **ривок «WULD»** (Z)
- **Лава** обпікає, **зілля мани** автоматично п'ється під час каста
- **Торговець Гундар** (E біля нього) — купівля/продаж за золото
- **Міні-бос «Гірський троль»** з'являється періодично

**Графіка / рушій**
- **Гладкий 3D-ландшафт** (heightmap, smooth shading) з природним змішуванням біомів
- **Шейдерна вода**: біжать хвилі, Френель, сонячні відблиски, прозорість
- **Low-poly 3D моделі** дерев/каміння/руди/істот зі згладженими нормалями
- **Інстансована трава** (тисячі) з анімацією вітру у вершинному шейдері
- **Bloom-постпроцесинг** (UnrealBloomPass) — світіння вогню/магії/руди/вівтаря
- Динамічні **тіні** (PCF Soft), ACES tone mapping, sRGB, експоненційний туман
- **Шейдерне небо** з диском сонця, місяць, зорі, хмари
- Повний **цикл день/ніч** + **погода**: ясно / дощ / **гроза з блискавками**
- Звукові ефекти (WebAudio, без файлів)

**Інтерфейс і зручності**
- **Мінікарта-радар** (вороги, дракон, скрині, вівтар)
- **Смужки здоров'я** над ворогами, підсвічування прицілу на цілі
- **Меню налаштувань**: чутливість миші, гучність, FOV, дальність промальовки
- **Збереження прогресу** (автозбереження + кнопка «Продовжити»), світ за сідом
- **Скрині зі скарбами**, більший світ, валуни-орієнтири, фаза приземлення дракона

## Керування

| Клавіша | Дія | | Клавіша | Дія |
|---|---|---|---|---|
| `W A S D` | рух | | `Q` | Крик «ФУС РО ДА» |
| Миша | огляд | | `F` | магія вогню |
| `Пробіл` | стрибок | | `R` | магія льоду |
| `Shift` | біг | | `E` | взаємодія / підбір |
| `ЛКМ` | атака / рубати-копати | | `P` / `C` | навички / крафт |
| `ПКМ` | поставити факел | | `G` | стріляти з лука |
| `1–4` | вибір предмета | | `V` / `H` | блискавка / лікування |
| `E` | взаємодія / торговець / збір | | `Z` | ривок (Крик) |
| `Esc` | пауза | | `F11` / `F12` | повний екран / DevTools |

**Мета:** дійди до 3 рівня, активуй вівтар у центральній вежі (`E`) і здолай дракона.

## Запуск (розробка)

```bash
cd skyrimcraft
npm install
npm start
```

## Збірка `.exe` для Windows

```bash
cd skyrimcraft
npm install
npm run dist
```

Готові файли з'являться в теці `dist/`:
- `SkyrimCraft-1.0.0-x64.exe` — інсталятор (NSIS, з ярликами)
- `SkyrimCraft-1.0.0-portable.exe` — портативна версія (без встановлення)

> **Примітка:** збирати Windows-`.exe` найнадійніше на Windows. На Linux/macOS
> electron-builder може зібрати через Wine, але офіційно рекомендується цільова ОС.
> Для Linux: `npm run dist:linux` (створить `.AppImage`).

### Іконка (необов'язково)
Поклади `build/icon.ico` (256×256) та `build/icon.png`, щоб задати власну іконку.
Без них використовується стандартна іконка Electron.

## Структура

```
skyrimcraft/
├── package.json      # залежності + конфіг electron-builder
├── main.js           # головний процес Electron (вікно)
├── preload.js        # безпечний міст (contextIsolation)
└── src/
    ├── index.html        # HUD та меню
    ├── style.css         # стилі інтерфейсу
    ├── game.js           # 3D-рушій гри (ландшафт, вода, істоти, геймплей)
    ├── three.min.js      # Three.js (vendored, офлайн)
    └── postprocessing.js # EffectComposer + UnrealBloomPass (vendored)
```
